# Orris House booking-ready demo

This is a standalone static website and can be uploaded as-is to Netlify, Vercel, GitHub Pages, or another web host.

## Working front-end features

- Treatment, practitioner, date, and time selection with a live booking summary
- Client detail validation and booking-request confirmation
- Treatment content, membership promotion, testimonials, contact details, and Google Map embed

## What a live booking business needs next

To accept actual appointments, payments, email confirmations, automated reminders, staff availability, customer accounts, and calendar synchronisation, connect the booking form to a secure back end or a booking provider such as Fresha, Calendly, Setmore, or a custom system.

The studio, practitioner, address, pricing, and email details are fictional demo content and must be replaced before launch.
