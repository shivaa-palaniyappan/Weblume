# Forge / Form gym demo

This standalone static website can be uploaded as-is to Netlify, Vercel, GitHub Pages, or any standard web host.

## Included in the front-end demo

- Membership plans, classes, coach profiles, transformations, reviews, nutrition, product cards, and Google Map embed
- Interactive schedule switcher, BMI calculator, calorie estimator, shopping-bag count, and trial-request confirmation
- A visual admin dashboard concept

## Build requirements for a real gym

Online registration, bookings, payments, member logins, secure admin management, and saving form submissions need a back-end, authentication, payment provider, and database. The current interactions are intentionally front-end demos.

Before launch, replace all fictional trainer names, prices, testimonials, contact details, and the map location with the client’s real information.
