# Aster & Oat café demo

This is a standalone static website. To host it, upload this entire `cafe-demo` folder to Netlify, Vercel, GitHub Pages, or any ordinary web host.

The home page is `index.html`. The portfolio’s first project card already links to `cafe-demo/index.html`; after you publish it, replace that relative link in `../index.html` with your new public URL.

The café name, address, hours, email, menu text, and prices are demo content and should be replaced with a client’s real details before launch.
